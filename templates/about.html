THE PURPOSE / ABOUT

About the Project

Exoplanet Hunter is an AI-powered astronomy project combining NASA’s Kepler observations with machine learning to investigate patterns in potential exoplanet signals.

THE QUESTION STARTS WITH LIGHT.

01 / THE MISSION

Making distant worlds
a little more accessible.

Exoplanet Hunter brings historical Kepler observations into an approachable space for exploration. It is a college AI/ML mini project about understanding astronomical data and the patterns a machine-learning model can learn from it.

Browse actual catalog records, investigate measurements, and compare a model’s interpretation with the original NASA disposition.

03 / THE MODEL

Patterns, not proof

A saved Random Forest pipeline handles missing measurements with median imputation and assigns a Planet-like or False Positive classification.

Random Forest was selected after comparison with Logistic Regression and an Artificial Neural Network.

05 / SCIENTIFIC RESPONSIBILITY

Keep the wonder.
Respect the uncertainty.

These predictions are experimental model outputs, not discoveries or confirmations. The model learns from historical observations and may make mistakes.

A class-1 score describes the model’s output, not the scientifically verified probability that an exoplanet exists. Candidate and confirmed training observations share the Planet-like label.

The final test set was inspected during development. Historical performance should not be interpreted as an untouched independent benchmark.
